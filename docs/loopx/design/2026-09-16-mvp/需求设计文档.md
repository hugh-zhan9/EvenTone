# EvenTone MVP 实现合同

来源与状态：[概要设计](概要设计.md)。用户已批准功能方向并授权 MVP 实施；以下为范围内实现选择，2026-09-16。

## 模块和数据

Swift Package 管理原生 SwiftUI 可执行程序和 C11 AudioDSP，无第三方依赖。AudioWorker 在专用串行队列管理 AudioRouter 与设备监听，所有 HAL 查询、创建、销毁均在该队列；主线程只发布界面状态。实际验证发现 HAL 调用可能等待几十秒，因此界面不等待同步 HAL 调用；退出由操作系统回收进程私有对象，同时排队尝试主动清理。IO 回调调用预分配 C DSP；配置和仪表读数通过 C 原子值传递，不在实时回调分配内存、加锁、记录日志或操作界面。

UserDefaults 保存全局输出衰减（0…1，默认 0.8）、自动均衡（默认 true）、设备补偿字典（UID → dB，-12…+12），以及总开关 processingEnabled（默认 false）。AppModel 初始化时在首次设备刷新之前加载总开关；总开关每次变化时写入，退出清理不修改。启动规则见 [D-006](概要设计.md#D-006)。无有效数值恢复字段默认值；不存在 UID 使用 0 dB。设备配置互不覆盖。

均衡目标约 -22 dBFS RMS，自动增益 -18…+12 dB；静音门限约 -55 dBFS。分析窗口和增益调整平滑，减小增益快于增大增益；最终使用关联声道峰值限幅。UI 显示输入 / 输出 dBFS 与当前自动增益，不把 RMS 标成 LUFS。

录制权限用途写入应用 Info.plist。失败显示 Core Audio 阶段和 OSStatus；权限由系统管理，提供系统设置入口。运行时错误尝试释放已分配资源；HAL 销毁失败时保留句柄与仍可能被回调使用的内存，并明确要求退出，不能提前释放。音频输出通路必须在 Float32、通道数与采样率验证后才能启动。

## 验证场景

| 场景 | 来源 | 检查方式 |
| --- | --- | --- |
| 两个 UID 补偿独立保存并重载 | AC-1 / D-002 | 配置单元测试；实物切换另行听测 |
| 相同波形不同输入幅度，稳定后输出差异缩小 | AC-2 / D-002 | DSP 合成信号 |
| 静音、极小信号、单帧、异常浮点值 | AC-2 / D-002 | DSP 边界测试 |
| 突然大声时峰值受限，左右声道比例保留 | AC-2 / D-002 | DSP 突变与立体声测试 |
| 关闭自动均衡后只做配置增益 | AC-2 / D-002 | DSP 测试 |
| 开关、退出、设备断开、拒绝权限 | AC-3 / D-003 | 原生资源生命周期与人工验收 |
| 无音频写盘或网络、原生权限说明 | AC-4 / D-001 | 源码审查、打包检查 |

新增验证：设备列表为空/单设备/连接变化、点击已断开设备、设置失败/等待确认/超时；成功切换后按 UID 恢复补偿并保留总开关意图。登录项覆盖开关成功、失败、待系统允许、外部状态变化和重开读回。实际登录启动需在用户下次登录确认，不通过主动注销验收。
